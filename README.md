# Phoenix AI (v3.0.0-prod)

Phoenix AI is a local, lightweight Python coding assistant, multi-agent framework, and model system. It operates fully on-device to ensure data privacy and maximum security.

## Core Features

- **Parameter-Efficient Fine-Tuning (LoRA PEFT)**: Wrap model attention and feed-forward layers with trainable adapters (`LoRALinear`) to tune efficiently on local hardware.
- **Multi-Agent Orchestrator**: Coordinates self-healing planning, execution, and verification loops (`Planner` -> `Executor` -> `QA` -> `Verifier` -> `Debugger`).
- **Coding Benchmarks**: Evaluate code generation accuracy using local assertion-based benchmarks (HumanEval/MBPP tasks).
- **Custom Byte-Level BPE Tokenizer**: Designed specifically for Python syntax with special token bindings for conversational loops and tool execution.
- **Transformer Decoder Model**: 8-layer causal transformer featuring RMSNorm, RoPE (Rotary Position Embeddings), SwiGLU activations, and KV Caching for fast inference.
- **Secure Subprocess Sandbox**: Runs Python code generated by the agent in an isolated, sandboxed subprocess with execution timeouts and strict environment isolation.
- **Long-Term Vector Memory**: Local semantic search engine using vectorized matrix multiplication (`torch.mv`) on the model's own embedding space for knowledge retention.
- **Docker Containerization**: Easily deploy the FastAPI backend and Nginx-powered React dashboard using docker-compose.
- **Conversational API & Dashboard**: Fast API server and a React Vite frontend dashboard for Chat, Sandbox, and Vector Memory exploration.

## Quick Start

### 1. Requirements

- Windows 11 / Windows 10 (or Linux/macOS with Docker)
- GPU: NVIDIA with 12GB VRAM (optional, falls back to CPU automatically)
- RAM: 16GB
- Python 3.10+
- Node.js (v18+)

### 2. Startup (Local)

To run the entire system (API + Frontend Dashboard) concurrently, simply run the launcher script from the root workspace:

```cmd
run_phoenix.bat
```

This will:
1. Activate the Python virtual environment and launch the FastAPI server at `http://127.0.0.1:8000`.
2. Launch the React Vite development server at `http://localhost:5173/` and open it in your browser.

### 3. Startup (Docker Compose)

Launch both services in containerized production mode:

```bash
docker-compose up --build
```

The React dashboard is exposed at `http://localhost`, proxying backend calls to the FastAPI container.

