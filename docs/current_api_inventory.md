# Phoenix AI - جرد واجهات برمجة التطبيقات الحالية (Current API Inventory)

يقدم هذا المستند جردًا وتفصيلًا هندسيًا شاملًا لجميع واجهات برمجة التطبيقات (APIs) المتاحة في خادم FastAPI لمنصة **Phoenix AI**، مع تحديد متطلبات التحقق والصلاحيات وهيكل المدخلات والمخرجات.

---

## 1. نظرة عامة على صلاحيات ومستويات الوصول (RBAC & Auth Policy)

تنقسم المسارات إلى مسارات عامة (Public) ومسارات محمية تتطلب رمز JWT من نوع `access` مع صلاحيات محددة بناءً على هيكلية الأدوار (Role Hierarchy):

* **المشرف (Admin)**: يتمتع بكامل الصلاحيات بما في ذلك النسخ والضغط والتهيئة.
* **المطور (Developer)**: تشغيل الأكواد والتدقيق وإعادة الهيكلة والتنسيق.
* **المشغل (Operator)**: رفع المستندات للذاكرة وإضافة النماذج للمستكشف.
* **المستخدم العادي (User)**: المحادثة والبحث والاستعلام الأساسي.

## 3. تفاصيل هياكل النماذج والطلبات (Request & Response Payloads)

### أ. خدمات المصادقة (Auth Endpoint)
#### تسجيل الدخول (`POST /api/auth/login`)
* **طلب المدخلات (JSON)**:
  ```json
  {
    "username": "admin",
    "password": "yourpassword"
  }
  ```
* **الاستجابة الناجحة (HTTP 200)**:
  ```json
  {
    "access_token": "eyJhbGciOiJIUzI1NiIsIn...",
    "refresh_token": "eyJhbGciOiJIUzI1NiIsIn...",
    "token_type": "bearer",
    "role": "admin",
    "username": "admin"
  }
  ```

---

### ب. محرك المحادثة والاستدلال (Chat Engine)
#### إرسال محادثة (`POST /api/chat`)
* **طلب المدخلات (JSON)**:
  ```json
  {
    "prompt": "اكتب كود حساب العاملي في بايثون",
    "temperature": 0.2,
    "max_tokens": 512
  }
  ```
* **الاستجابة الناجحة (HTTP 200)**:
  ```json
  {
    "response": "بالتأكيد، إليك كود حساب العاملي (Factorial)..."
  }
  ```
* **شروط التحقق**: طول البرومبت المسموح لا يتجاوز `10,000` رمز، ويتم فحصه فوراً ضد هجمات حقن الأوامر والبرومبت.

---

### ج. محرك الذاكرة المعرفية (RAG & Memory)
#### البحث الدلالي المتطور (`POST /api/memory/search`)
* **طلب المدخلات (JSON)**:
  ```json
  {
    "query": "ما هي متطلبات النشر السحابي لمنصة Phoenix AI؟",
    "top_n": 5,
    "mode": "hybrid"
  }
  ```
* **الاستجابة الناجحة (HTTP 200)**:
  ```json
  {
    "results": [
      {
        "text": "مستند النشر السحابي يشترط استخدام Docker Compose...",
        "metadata": {
          "type": "upload",
          "importance": 1.45
        },
        "score": 0.892
      }
    ]
  }
  ```
* **أوضاع البحث (Modes)**:
  * `dense`: بحث دلالي خالص باستخدام التضمين الرياضي.
  * `hybrid`: دمج نتائج البحث الدلالي مع مطابقة الكلمات المفتاحية (TF-IDF).
  * `graph_rag`: استرجاع ذكي بالاعتماد على شبكة العلاقات والكيانات المعرفية KG Graph.

---

### د. المعزل الآمن للأكواد (Sandbox Runtime)
#### تشغيل الكود المعزول (`POST /api/sandbox/run`)
* **طلب المدخلات (JSON)**:
  ```json
  {
    "code": "print('Hello Phoenix Sandbox')",
    "timeout": 5.0
  }
  ```
* **الاستجابة الناجحة (HTTP 200)**:
  ```json
  {
    "stdout": "Hello Phoenix Sandbox\n",
    "stderr": "",
    "exit_code": 0,
    "duration": 0.052,
    "sandboxed": true
  }
  ```
* **شروط التحقق**: حجم الكود المسموح لا يتجاوز `64KB` (65,536 بايت)، ومهلة التنفيذ القصوى المحددة هي `30` ثانية.
