# تقرير الدفاع ضد تسميم مستندات RAG — Phoenix AGI

## 1. المتطلبات والتصميم
- **الهدف**: حماية قاعدة بيانات المتجهات (Vector Store) من محاولات التسميم أو حقن توجيهات خفية داخل الملفات المرفوعة أو سجلات الذاكرة المضافة.
- **التصميم**:
  - يتم التحقق من صحة امتدادات الملفات المرفوعة وحجمها الأقصى (5 ميجابايت) ونوعها (.txt، .md، .py، .csv، .json) قبل المعالجة.
  - يقوم النظام بفك وتفسير نصوص المستندات وفحصها أمنياً عند استدعاء واجهات الذاكرة المتجهة.
  - يتم استخدام آلية الفحص `is_prompt_injection` للتأكد من خلو محتوى الملفات من عبارات كسر الحماية أو تجاوز التعليمات.
  - يتم رفض الملفات المشبوهة فوراً بترميز **HTTP 400 Bad Request** لضمان نظافة وعزل قاعدة البيانات المعرفية.

## 2. نقاط النهاية المحمية
- **واجهة رفع المستندات (`/api/memory/upload`)**
- **واجهة إضافة سجلات الذاكرة يدوياً (`/api/memory/add`)**
