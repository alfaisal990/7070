# وثيقة النماذج التخطيطية لهيكل الواجهات (Wireframes Specification) - Phoenix AI

تحدد هذه الوثيقة الهياكل التخطيطية (Wireframes) المعتمدة لتصميم صفحات لوحة تحكم منصة **Phoenix AI** عبر منصات العرض المختلفة (الحاسوب الشخصي، الأجهزة اللوحية، والهواتف المحمولة).

---

## 1. الهيكل العام للتصميم (Main Layout Grid)

### أ. تصميم الحاسوب الشخصي (Desktop Wireframe - 1280px+)

```text
+------------------------------------------------------------------------------------+
| [Phoenix AI]  |  [💬 Assistant] [💻 Sandbox] [🧠 Memory] [🔧 Debugger]             |
| Status: ONLINE|  Active View: Chat Assistant                                       |
+---------------+--------------------------------------------------------------------+
|               |                                                                    |
| [Sidebar]     |  +---------------------------------------------------------------+ |
| - Chat        |  | (AI) Hello! I am Phoenix AI, how can I help you write Python?| |
| - Sandbox     |  +---------------------------------------------------------------+ |
| - Memory      |  | (User) Write a script to calculate fibonacci.                 | |
| - Debugger    |  +---------------------------------------------------------------+ |
| - Refactor    |  |                                                               | |
| - AI Explorer |  | [ Messages Display Container ]                                | |
|               |  +---------------------------------------------------------------+ |
| [Backup DB]   |  | [Input Text prompt here...                     ] [Stream: [x]] | |
| [Scan Code]   |  +---------------------------------------------------------------+ |
|               |                                                                    |
+------------------------------------------------------------------------------------+
```

* **خصائص العرض**:
  * قائمة جانبية ثابتة ومستمرة بعرض 260px.
  * محتوى أساسي مرن يستغل المساحة المتبقية.
  * نافذة التنبيهات المنبثقة (Toasts) تظهر في الركن الأيمن السفلي.

---

### ب. تصميم الأجهزة اللوحية (Tablet Wireframe - 768px to 1024px)

```text
+------------------------------------------------------------------------------------+
| [Phoenix AI]  (Status: ONLINE)  [Menu Toggle]                                      |
+------------------------------------------------------------------------------------+
|                                                                                    |
|  Active View: Secure Code Execution Sandbox                                        |
|                                                                                    |
|  +------------------------------------------------------------------------------+  |
|  | [Code Editor Area]                                                           |  |
|  | def greet(name):                                                             |  |
|  |     return f"Hello, {name}!"                                                 |  |
|  |                                                                              |  |
|  +------------------------------------------------------------------------------+  |
|  | Timeout: [5.0] s                  [ RUN CODE BUTTON ]                        |  |
|  +------------------------------------------------------------------------------+  |
|  | [Console Output Terminal]                                                    |  |
|  | stdout: Hello, Phoenix AI!                                                   |  |
|  +------------------------------------------------------------------------------+  |
|                                                                                    |
+------------------------------------------------------------------------------------+
```

* **خصائص العرض**:
  * إخفاء القائمة الجانبية وتحويلها لقائمة منسدلة علوية (Collapsed Hamburger Menu) لتوفير مساحة العرض العرضية.
  * تكبير مساحات حقول الإدخال لتسهيل الكتابة باللمس.

---

+------------------------------------+

+------------------------------------+

* **خصائص العرض**:

  * استغلال كامل مساحة العرض للهاتف.
