# وثيقة مواصفات واجهات البرمجة (API Specifications) - Phoenix AI

تحدد هذه الوثيقة مواصفات وهياكل واجهات برمجة التطبيقات (REST APIs) لمنصة **Phoenix AI** بما في ذلك نماذج المدخلات والمخرجات، والرموز التعريفية للأخطاء المتوقعة.

---

## 1. مسارات ونقاط الوصول الأساسية (REST Endpoints)

### أ. خدمة محادثة المساعد الذكي (`POST /api/chat`)
تُستخدم لإرسال توجيه برمجية للمساعد الذكي واستلام الاستجابة النصية المكاملة.
* **رأس الطلب (Headers)**: `Content-Type: application/json`
* **جسم الطلب (Request Body)**:
  ```json
  {
    "prompt": "اكتب دالة بلغة بايثون لحساب مضروب العدد n",
    "temperature": 0.2,
    "max_tokens": 512
  }
  ```
* **جسم الاستجابة الناجحة (`200 OK`)**:
  ```json
  {
    "response": "دالة حساب مضروب العدد بلغة بايثون هي:\n\n```python\ndef factorial(n):\n    if n == 0:\n        return 1\n    return n * factorial(n-1)\n```"
  }
  ```

---

### ب. خدمة تشغيل الأكواد المعزولة (`POST /api/sandbox/run`)
تُستخدم لتشغيل كود بايثون داخل بيئة تنفيذ معزولة والتأكد من سلامة مخرجاته.
* **جسم الطلب (Request Body)**:
  ```json
  {
    "code": "print(sum(range(10)))",
    "timeout": 5.0
  }
  ```
* **جسم الاستجابة الناجحة (`200 OK`)**:
  ```json
  {
    "status": "success",
    "stdout": "45\n",
    "stderr": "",
    "exit_code": 0
  }
  ```

---

### ج. خدمة البحث في الذاكرة المتجهية (`POST /api/memory/search`)
البحث في مستندات وسجلات الذاكرة المعرفية RAG دلالياً.
* **جسم الطلب (Request Body)**:
  ```json
  {
    "query": "مكتبات معالجة اللغات الطبيعية في بايثون",
    "top_n": 3,
    "mode": "hybrid"
  }
  ```
* **جسم الاستجابة الناجحة (`200 OK`)**:
  ```json
  {
    "results": [
      {
        "similarity": 0.89,
        "text": "تعتبر مكتبة Transformers من أشهر المكتبات لتشغيل النماذج اللغوية الكبيرة.",
        "metadata": {
          "type": "manual",
          "importance": 1.2
        }
      }
    ]
  }
  ```

---

### د. فحص الجاهزية والتشغيل (`GET /api/health/readiness`)
فحص فوري لجاهزية النماذج والذاكرة المدمجة لاستقبال الطلبات الفعلية.
* **جسم الاستجابة الناجحة (`200 OK`)**:
  ```json
  {
    "status": "ready",
    "components": {
      "model": true,
      "tokenizer": true,
      "memory_store": true,
      "engine": true
    }
  }
  ```

## 2. رموز الاستجابة وأكواد الأخطاء (Error Codes & Responses)

تعتمد المنصة معايير أخطاء HTTP القياسية مقترنة بتفاصيل توضيحية خالية من معلومات النظام الحساسة:

| رمز الحالة | كود الخطأ | السبب الشائع والوصف |
| :---: | :--- | :--- |
| `400` | `Bad Request` | تجاوز الحد الأقصى للمدخلات (Prompts/Code) أو كشف محاولات حقن التوجيهات أو تسميم الذاكرة. |
| `401` | `Unauthorized` | عدم إرسال أو انتهاء صلاحية رمز التحقق JWT المرفق بترويسة الطلب. |
| `404` | `Not Found` | استدعاء فئات غير متواجدة في مستكشف النماذج أو مسار خاطئ. |
| `429` | `Too Many Requests` | تجاوز معدل الطلبات المسموح به للمستخدم النهائي في النافذة الزمنية المحددة. |
| `500` | `Internal Server Error` | خطأ خادم داخلي غير متوقع؛ يتم حظر تفاصيله وإرجاع معرّف تتبع فريد UUID للمستخدم. |
| `503` | `Service Unavailable` | عدم تحميل النماذج أو الذاكرة بعد (مرحلة بدء إقلاع النظام). |
