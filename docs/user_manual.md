# دليل المستخدم ومشغل النظام (User & Operator Manual) - Phoenix AI

يوضح هذا المستند دليل التشغيل الكامل لمنصة **Phoenix AI** ويضم أقساماً مخصصة للمطورين (المستخدم النهائي)، والمدراء (Operators)، ومشرفي الأنظمة (Administrators).

---

## 1. دليل المطور والمستخدم النهائي (Developer User Guide)

يساعد هذا القسم المطورين على استغلال ميزات المنصة البرمجية:

### أ. محادثة المساعد الذكي (Chat Assistant)
1. انتقل لتبويب **المساعد الذكي (AI Assistant)** من القائمة الجانبية.
2. اكتب سؤالك البرمجي أو اطلب توليد كود في صندوق الإدخال السفلي.
3. فعّل **وضع البث المباشر (Stream Mode)** لمشاهدة ردود النموذج وهي تتولد لحظة بلحظة، أو عطلها لاستلام الرد ككتلة نصية كاملة.
4. اضغط **إرسال** أو مفتاح `Enter`.

### ب. تشغيل الأكواد في المحاكي الآمن (Code Sandbox)
1. انتقل لتبويب **محاكي الأكواد (Code Sandbox)**.
2. اكتب كود بايثون التجريبي في محرر النصوص.
3. حدد مهلة التنفيذ بالثواني (الوضع الافتراضي 5 ثوانٍ).
4. اضغط **تشغيل الكود (Run Code)**. ستظهر مخرجات التنفيذ والخطأ (إن وجد) في لوحة الكونسول السفلية فوراً.

### ج. إصلاح الأخطاء تلقائياً (Workspace Debugger)
1. انتقل لتبويب **مكتشف الأخطاء (Debugger)**.
2. اضغط **فحص مساحة العمل (Scan Workspace)** لقراءة ملفات مساحة عملك وكشف الأخطاء التلقائية.
3. ستظهر المشاكل المكتشفة في جدول تفاعلي.
4. اضغط زر **إصلاح تلقائي (Auto-Repair)** بجوار الخطأ المراد حله، وسيقوم الوكيل بتعديل الكود وحل المشكلة.

## 2. دليل مشرفي الأنظمة والتعافي (Administrator Runbook)

مخصص لمدراء الخوادم لضمان سلامة واستقرار تشغيل المنصة:

### أ. إدارة ومراقبة الصحة والجاهزية
* يتم تتبع صحة الحاويات والخدمات عبر واجهات فحص الجاهزية والحياة:
  * الرابط: `/api/health/readiness` (يجب أن يعيد `200 OK` وحالة جاهزية كافة المكونات اللغوية).
  * الرابط: `/api/health/liveness` (التحقق من عمل الخادم العام).
* لمراقبة أحمال الشبكة وسرعة الاستدلال، تصفح واجهة Prometheus المتوافقة بالمسار `/metrics` ودمجها مع لوحات Grafana.

### ب. إجراء نسخ احتياطي فوري لقواعد البيانات
لإنشاء نسخة احتياطية بشكل يدوي وآمن لقاعدة بيانات الذاكرة، يمكن لمدير النظام استدعاء نقطة النهاية المخصصة أو استخدام النصوص المرفقة:
* **عبر خادم ويندوز (PowerShell)**:
  ```powershell
  powershell -ExecutionPolicy Bypass -File .\backup_restore.ps1 -Action backup
  ```
* **عبر خادم لينكس (Bash)**:
  ```bash
  ./backup_restore.sh backup
  ```

### ج. سيناريو الاستعادة والتعافي من الكوارث (Restore Database)
في حال تعرض ملف الذاكرة المعرفية للتلف أو الفقدان، اتبع الخطوات التالية لاستعادة آخر نسخة مستقرة:
1. أوقف تشغيل الخدمات المفتوحة لمنع عمليات الكتابة المتزامنة.
2. قم بتشغيل سكربت الاستعادة التلقائي:
   * **على ويندوز**:
     ```powershell
     powershell -ExecutionPolicy Bypass -File .\backup_restore.ps1 -Action restore
     ```
   * **على لينكس**:
     ```bash
     ./backup_restore.sh restore
     ```
3. ستقوم الأداة بالتحقق التلقائي من سلامة بنية أحدث نسخة احتياطية واستعادة قاعدة البيانات مع الاحتفاظ بنسخة أمان مؤقتة لضمان التراجع الآمن عند الفشل.
4. أعد تشغيل الخدمات وتفحص نقطة `/api/health/readiness` للتأكد من تمام تحميل البيانات.
