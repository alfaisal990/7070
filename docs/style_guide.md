# دليل الهوية والتنسيق البصري (Style Guide) - Phoenix AI

يحدد هذا المستند نظام التنسيق البصري (Design System) والألوان والخطوط والفراغات المعتمدة لواجهات منصة **Phoenix AI** لضمان الاتساق الجمالي وتجربة مستخدم متميزة.

## 2. الفراغات والخطوط وهيكل الصفحات (Typography & Spacing)

### أ. نظام الخطوط (Typography)
* **عائلة الخط المعتمدة للواجهة**: خط `Inter` أو خطوط النظام المماثلة للتوافق العالي.
* **خط الأكواد والـ Console**: خط `JetBrains Mono` أو `Fira Code` مع تفعيل خصائص التلوين البرمجي.
* **أحجام النصوص**:
  * العناوين الكبرى (`h2`): 1.5rem (24px) بوزن عريض (Bold).
  * العناوين الفرعية (`h3`): 1.25rem (20px) بوزن متوسط.
  * النصوص العامة ومحتويات الجداول: 0.875rem (14px).

### ب. الهوامش والفراغات (Spacing Scale)
* يتم ضبط الهوامش الداخلية (Padding) والخارجية (Margin) بالاعتماد على مضاعفات الرقم 4 لتأمين توازن بصري دائم:
  * الفراغات البسيطة والحدود: `4px` أو `8px`.
  * الفراغات بين العناصر المترابطة: `12px` أو `16px`.
  * الهوامش الداخلية للصناديق والألواح الأساسية: `24px` أو `32px`.
* **دليل الحواف (Border Radius)**: يتم تدوير حواف الأزرار واللوحات بمقدار `8px` أو `12px` لإعطاء مظهر عصري ناعم.
* **التأثيرات التفاعلية (Micro-animations)**: إضافة تأثير انتقال سلس `transition: all 0.2s ease` لجميع الأزرار والروابط التفاعلية عند مرور الفأرة لمنح حركة متجاوبة للواجهة.
