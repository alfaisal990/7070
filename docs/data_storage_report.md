# تقرير بنية وتخزين البيانات (Data & Storage Report) - Phoenix AI

يوضح هذا المستند تقييماً للبنية التخزينية الحالية، قواعد البيانات، ملفات المعرفة، والذاكرة المتجهية المستخدمة في منصة **Phoenix AI** وتحديد الثغرات ونقاط التطوير.

---

## 1. البنية التخزينية الحالية (Current Storage Architecture)

تعتمد المنصة حالياً على التخزين الخفيف محلياً في مساحة العمل دون الاعتماد على خوادم قواعد بيانات خارجية:

### أ. ملف الذاكرة المعرفية (`memory_db.json`)
* **المسار**: `ai_project/memory/memory_db.json`
* **المحتوى**: يخزّن هذا الملف كائنات الذاكرة التي أضيفت يدوياً أو تم استخلاصها من المستندات المرفوعة.
* **البنية البرمجية**: كائن JSON يحتوي على:
  * قائمة `memories`: تضم النص الأساسي للمستند، متجهات الأبعاد اللغوية المستخلصة، وحقول البيانات الوصفية (حجم الاستخدام، تاريخ آخر وصول، معامل الأهمية التشغيلية).
  * كائن `kg_graph`: يمثل الرسم البياني للمعرفة المعرفية لحفظ علاقات الكيانات المستخلصة.

### ب. ملف مستودع نماذج الذكاء الاصطناعي (`ai_data.json`)
* **المسار**: `ai_project/api/ai_data.json`
* **المحتوى**: كائن JSON بسيط مبوب يخزن تصنيفات وعائلات وموديلات الذكاء الاصطناعي التي يتم عرضها والبحث فيها وتحديثها عبر صفحة مستكشف النماذج الذكية.

### ج. الذاكرة التخزينية للمتجهات (Vector Cache)
* **المكون**: يتم تحميل متجهات التمثيل دلالياً من ملف JSON عند بدء التشغيل وتخزينها في ذاكرة النظام النشطة باستخدام هياكل PyTorch Tensors لتسريع عمليات ضرب مصفوفات البحث دلالياً.

## 2. الفجوات التشغيلية والهندسية للتخزين (Identified Storage Gaps)

1. **الافتقار لقواعد البيانات العلائقية (No SQL/RDBMS Support)**:
   * يتم تخزين كافة التكوينات والمستندات وعائلات النماذج في ملفات JSON مسطحة. يعرض هذا النظام البيانات لخطر الفقدان أو التلف عند الكتابة المتزامنة المتعددة (Concurrent Writes) ويفتقر لمعايير معاملات ACID المتكاملة.
2. **عدم كفاءة البحث في ملفات JSON**:
   * يتطلب البحث أو فرز السجلات استعراض وقراءة الملف بالكامل في الذاكرة العشوائية، وهو ما يؤدي لتدهور ملحوظ في الأداء ومعدلات الاستجابة كلما زاد حجم السجلات والذكريات.
3. **غياب طبقة التخزين المؤقت المستقلة (No Independent Caching)**:
   * لا يوجد محرك للتخزين المؤقت السريع (مثل Redis) لإدارة كاش المتجهات، المقاييس التشغيلية، أو الجلسات النشطة للمستخدمين، مما يضطر النظام للاعتماد على متغيرات بايثون العامة المعرضة للضياع عند إعادة التشغيل.
4. **غياب تصاريح وتأمين الوصول الجغرافي للبيانات**:
   * غياب أدوات تشفير البيانات المخزنة على الأقراص (Data-at-Rest Encryption)؛ حيث يتم حفظ كافة نصوص ومستندات ومعلومات قاعدة بيانات الذاكرة بصيغة نصوص واضحة غير مشفرة (Plain Text) داخل ملف الـ JSON.
