# Phoenix AI - جرد هيكلية الواجهات الأمامية الحالية (Current Frontend Inventory)

يوضح هذا الملف جردًا وتفصيلًا هندسيًا شاملًا للواجهة الأمامية لمنصة **Phoenix AI** والمصممة بأسلوب عصري متقدم وتعتمد على تقنيات حديثة.

---

## 1. المكدس التقني للواجهة (Frontend Tech Stack)

* **الإطار الأساسي**: React 18 (Vite كمحرك بناء وتجميع سريع).
* **التنسيق والتصميم**: Vanilla CSS (مكتوب بالكامل في `src/index.css`) بدون الاعتماد على أطر عمل خارجية مثل Tailwind لضمان سرعة التحميل القصوى والتحكم الإبداعي الكامل.
* **إدارة الحالة**: React State Hook الموزع والمنظم عبر خطافات مخصصة (Custom Hooks) لتنظيم الاتصال وفصل منطق العمل (Business Logic) عن طريقة العرض (Rendering).
* **إدارة الاتصال والشبكة**: Fetch API معالجة مدمجة تدعم التوثيق والمصادقة وإرفاق رموز JWT المحدثة.

---

## 2. دليل جرد الصفحات والتبويبات (Pages Directory)

يحتوي مجلد `src/pages/` على 6 صفحات رئيسية تمثل التبويبات التشغيلية للمنصة:

| الصفحة | اسم الملف | الوصف وميزات الواجهة |
|:---|:---|:---|
| **صفحة المحادثة** | `ChatPage.jsx` | واجهة دردشة للمساعد اللغوي تدعم التبديل بين الاستلام الفوري أو تدفق النص (Stream Mode) المباشر، وتخزين سجلات الجلسة. |
| **صفحة المعزل** | `SandboxPage.jsx` | محرر أكواد برمجية مدمج بمهلة تشغيل متغيرة لعرض مخرجات الأكواد والأخطاء بالتزامن مع تنفيذها الآمن بالخلفية. |
| **صفحة الذاكرة** | `MemoryPage.jsx` | إدارة بنك متجهات RAG مع إمكانية البحث الدلالي المكثف، استعراض نتائج التطابق، وإضافة وثائق يدوية ببيانات وصفية JSON. |
| **صفحة مصحح الأخطاء**| `DebuggerPage.jsx` | لوحة عرض أخطاء ملفات المشروع ومساحة العمل مع أزرار الإصلاح التلقائي اللحظية الفعالة. |
| **صفحة الهيكلة** | `RefactorPage.jsx` | واجهة لمقارنة وعرض الأكواد المحسنة بناءً على خيارات تحسين الكفاءة أو إعادة التنظيم أو التوثيق البرمجي. |
| **مستكشف النماذج** | `AIExplorerPage.jsx`| دليل وتصنيف نماذج الذكاء الاصطناعي العالمي مع خيارات البحث، وتدشين نافذة تفاعلية (Modal) لتسجيل الموديلات. |

## 3. المكونات الشاملة (Global Components)

تتواجد المكونات المشتركة داخل مجلد `src/components/`:

1. **شريط القائمة الجانبي (`Sidebar.jsx`)**:
   * يتحكم في التنقل بين الصفحات الستة.
   * يحتوي على مؤشر اتصال الخادم الحي (Online/Offline) الذي يقوم بالاستعلام الدوري كل 10 ثوانٍ.
   * يحتوي على زرين فوريين: تشغيل النسخ الاحتياطي بالخلفية وفحص مساحة العمل الفوري.
2. **عارض ومفسر الرسائل (`MessageRenderer.jsx`)**:
   * مفسر محتوى متطور يقوم بتحليل ردود الذكاء الاصطناعي.
   * يدعم تنسيقات Markdown والجداول والقوائم البرمجية.
   * يقوم بتسليط الضوء وتلوين صيغ الأكواد (Syntax Highlighting) المكتوبة بلغات متعددة (Python, Javascript, CSS...) لتسهيل القراءة.

## 4. الخطافات المخصصة وإدارة الحالة (Custom Hooks)

يتم تنظيم الحالة وتخزين البيانات عبر خطافات تفاعلية مخصصة داخل مجلد `src/hooks/`:

* **`useToast.js`**: يدير طابور الإشعارات المنبثقة التفاعلية (Toasts) بالنجاح أو الفشل أو التنبيه.
* **`useHealth.js`**: يراقب استجابة الخادم ويتحقق من اتصاله الدوري، ويطلق عمليات الحفظ الاحتياطي.
* **`useChat.js`**: يعالج إرسال واستقبال الرسائل وإدارة وضع الـ Stream بالتعاون مع الذاكرة.
* **`useSandbox.js`**: يتحكم في إعداد الأكواد المعزولة وقيود مهلة الانتظار واسترجاع مخرجات الـ Console.
* **`useMemory.js`**: يتولى عمليات البحث الدلالي ومسح المستودع وحفظ الكتل النصية بالبيانات الوصفية.
* **`useDebugger.js`**: يعالج إرسال طلبات فحص المجلدات واستقبال العلل وإطلاق دوال الإصلاح الفوري.
* **`useRefactor.js`**: يدير نصوص الأكواد المرسلة ونوع إعادة الهيكلة وعرض الكود الناتج.

## 5. منطق الخدمات والاتصال بالخلفية (`src/services/api.js`)

يمثل ملف `api.js` الواجهة البرمجية الموحدة لجميع اتصالات الواجهة الأمامية بالخادم:
* **إدارة رموز JWT**: يقوم بحقن رمز الـ Token تلقائياً في ترويسة الطلبات (Authorization Headers) تحت اسم `Bearer token`.
* **معالجة الأخطاء**: رصد الانقطاع بالشبكة وترجمة الاستجابات الخاطئة وإرجاع مخرجات نظيفة للـ Hooks.

---

## 6. الهوية البصرية والتصميم (`src/index.css`)

تتميز المنصة بتصميم بصري فاخر تم إعداده بدقة ليضاهي المواقع العالمية:
* **لوحة الألوان (Theme)**: مظهر داكن (Dark Theme) يعتمد على تدرجات Harmonized HSL وألوان فاخرة مثل الرمادي الفحمي للبيئات وجزئيات بنفسجية وكهرمانية للعناصر النشطة والتنبيهية.
* **تأثيرات الزجاج (Glassmorphism)**: استخدام خلفيات شفافة مع مرشحات الضباب الحركية (`backdrop-filter: blur`) للبطاقات والقوائم الجانبية لتوفير بعد بصري عميق.
* **الحركية والمؤشرات (Animations)**: تأثيرات حركية ناعمة عند تمرير الفأرة (Hover effects) والانتقال بين التبويبات، ومؤشر نابض (Pulse) لمستوى الاتصال، بالإضافة لمؤشر تحميل دائري متميز (Spinner) عند فحص البيانات.
* **التجاوبية الكاملة**: مرونة الواجهة للعمل على الشاشات الكبيرة والهواتف عبر استخدام الـ Flexbox وشبكات التنسيق (Grid layouts) المتجاوبة ذاتياً.
