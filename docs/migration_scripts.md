# تقرير نصوص الهجرة وترقية الأنظمة (Migrations & Upgrades) - Phoenix AI

يوضح هذا المستند تصميم وأتمتة نصوص ترحيل البيانات والهجرة (Migrations) لقواعد البيانات المتجهية والتقليدية والتكوينات البرمجية لمنصة **Phoenix AI** لبيئة الإنتاج.

---

## 1. هجرة وترقية قاعدة البيانات التقليدية (Schema Migrations)

مع توجه المنصة لاعتماد قواعد البيانات العلائقية (مثل PostgreSQL) لإدارة شؤون المستخدمين وسجلات التدقيق وسجل المحادثات، يتم تطبيق آلية الهجرة التالية:
* **الأداة المستخدمة**: **Alembic** (أداة ترحيل وهجرة قواعد البيانات الرسمية لـ SQLAlchemy في بايثون).
* **سيناريو العمل**:
  1. إنشاء مجلد الهجرة `alembic/` في مساحة عمل المشروع.
  2. توليد ملفات الهجرة التلقائية بناءً على التغيرات الحاصلة في نماذج البيانات (Models Schema) عبر الأمر:
     ```bash
     alembic revision --autogenerate -m "create core tables"
     ```
  3. تطبيق التعديلات ورفع الجداول في قاعدة بيانات الإنتاج الفعلي عبر الأمر:
     ```bash
     alembic upgrade head
     ```

## 2. هجرة بنك الذاكرة المتجهية (Vector DB Migration)

تم توفير وحدة المعالجة البرمجية للهجرة المتجهية في [vector_migration.py](file:///c:/Users/1/Desktop/7070/ai_project/memory/vector_migration.py) لنقل السجلات دلالياً من ملف JSON المحلي إلى محركات متطورة:
* **الهدف**: نقل البيانات بأمان مع صياغة البيانات الوصفية وبناء الفهارس دون تعريض الخدمات النشطة للتوقف.
* **الخطوات المنفذة للترقية**:
  1. فحص ملف `memory_db.json` وقراءته بالكامل وتحويل الأوزان لـ float32.
  2. إنشاء المجموعة المستهدفة في قاعدة بيانات المتجهات الجديدة (مثل Qdrant).
  3. استيراد البيانات كـ Batches للحد من استهلاك خادم المتجهات.
  4. استبدال محرك الاسترجاع ليتصل مباشرة بخادم المتجهات الجديد.

* تشمل هجرة متغيرات البيئة والتكوينات نقل ملفات إعدادات التطوير الفردية لتعمل مع ملفات بيئة الإنتاج الصارمة (مثل التخلي عن المفاتيح السرية الافتراضية لـ JWT، ونقل مسارات حفظ النسخ الاحتياطية لمسار ثابت خارج مجلدات البناء التلقائي للحاويات لضمان عدم تلف البيانات).
