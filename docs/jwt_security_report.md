# تقرير أمان مفاتيح رموز التحقق JWT — Phoenix AGI

## 1. المتطلبات والتصميم
- **الهدف**: منع نشر وتطوير المنصة في بيئات الإنتاج باستخدام مفاتيح أمنية افتراضية أو ضعيفة قد تسمح بتزوير الهويات.
- **Design**: تم إدراج مدقق للنموذج `@model_validator` باستخدام Pydantic ضمن إعدادات التكوين. يؤدي غياب متغير `SECRET_KEY` أو تطابقه مع الكلمات الافتراضية لمنع تشغيل الخدمة فوراً مع إرجاع الخطأ `ValidationError`.

## 2. قواعد التقوية الأمنية المطبقة
- **المفتاح المطلوب**: يعد حقل `SECRET_KEY` إلزامياً ولا يملك أي قيمة افتراضية.
- **المفاتيح المحظورة تماماً**:
  - `supersecretkeychangeinproduction`
  - `yoursecretkeyherechangeinproduction123`
- **السلوك المتوقع**: إرجاع رسالة خطأ صريحة تفيد بضرورة استخدام مفاتيح مخصصة قوية لتجنب مخاطر الاختراق وتزوير رموز المصادقة.
