## 3. العمليات التشغيلية لدورة حياة النظام (Lifecycle Operations)

لضمان سهولة الإدارة للعمليات الهامة في بيئة الإنتاج، تم توثيق والتحقق من الأوامر التالية:

### أ. بناء الصور والحاويات (Build)
يتم بناء الحاويات وتجهيزها محلياً أو في خادم النشر:
```bash
docker compose build
```

### ب. بدء التشغيل في الخلفية (Start)
لتشغيل الحاويات في وضع الفصل (Detached Mode):
```bash
docker compose up -d
```

### ج. إعادة التشغيل الآمن (Restart)
لإعادة تشغيل الحاويات وتطبيق التحديثات البيئية دون فقدان البيانات:
```bash
docker compose restart
```

### د. التراجع الفوري عن الإصدارات (Rollback)
في حال تعثر أي إصدار جديد، يتم إيقاف الحاويات الحالية واستعادة الإصدار المستقر السابق:
```bash
# إيقاف الإصدار الحالي
docker compose down
# استعادة الإصدار السابق (مثال باستخدام وسوم Git أو وسوم صور Docker)
docker compose up -d
```
