# تقرير الدفاع ضد حقن الأوامر (Prompt Injection) — Phoenix AGI

## 1. المتطلبات والتصميم
- **الهدف**: حماية نموذج اللغة الكبير (LLM) من المدخلات العدائية، ومحاولات تسريب التعليمات البرمجية الأساسية للنظام، وتجاوز التوجيهات الأصلية.
- **التصميم**: تم تطوير محرك فحص مبني على مطابقة بصمات تعبيرية نمطية (Regex) محددة تكتشف:
  - محاولات حظر أو تجاهل التوجيهات السابقة (Ignore instructions).
  - محاولات استخلاص أو تسريب محتوى توجيهات النظام الأصلية (System prompt leakage).
  - بصمات كسر الحماية الشهيرة مثل (DAN mode).
  يقوم النظام بإيقاف تشغيل الطلب فوراً عند الكشف عن سلوك مريب وإرسال استجابة بترميز **HTTP 400 Bad Request** للمستخدم لتفادي استغلال النموذج.

## 2. نقاط النهاية المحمية
- **واجهة محادثة العميل (`/api/chat`)**: تفحص مدخلات JSON قبل تمريرها لمعالجة الطلب في حلقة عمل العميل.
- **واجهة التدفق المباشر للمحادثة (`/api/chat/stream`)**: تعترض الاستفسارات قبل الاتصال بمولد التدفق.
