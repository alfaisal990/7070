# تقرير خط أنابيب التطوير المستمر CI/CD — Phoenix AGI

## 1. المتطلبات والتصميم
- **الهدف**: إعداد وضبط نظام تكامل وتطوير مستمر (CI) آلي بالكامل للتأكد من سلامة الكود البرمجي وتشغيل كافة اختبارات المنصة للتثبت من المخرجات مع كل دفع أو سحب للتغييرات البرمجية.
- **التصميم**:
  - تم تكوين خط أنابيب التطوير المستمر لـ GitHub Actions في الملف [.github/workflows/ci.yml](file:///c:/Users/1/Desktop/7070/.github/workflows/ci.yml).
  - يتم تشغيل خط الأنابيب تلقائياً عند دفع تغييرات أو سحب طلبات الفروع الموجهة للفرعين `main` أو `master`.
  - يوفر النظام بيئة عمل افتراضية مبنية على خادم Ubuntu مع تهيئة إصدار بايثون 3.12 وتفعيل التخزين المؤقت (Caching) لـ pip لتسريع دورة البناء.
  - يقوم بتنصيب المتطلبات اللازمة واستدعاء إصدارات PyTorch المخصصة للمعالجات المركزية (CPU-targeted PyTorch).
  - يتم تمرير المفاتيح السرية وبيانات اختبار JWT الوهمية كمتغيرات بيئية آمنة لتجاوز فحوصات تشغيل الخادم.
  - يستدعي ويعمل على تشغيل اختبارات بايثون pytest المقسمة لثلاث مجموعات متكاملة.
