# تقرير النسخ الاحتياطي التلقائي — Phoenix AGI

## 1. المتطلبات والتصميم
- **الهدف**: بناء نظام موثوق وآمن ولا يعتمد على برامج خارجية لنسخ قاعدة بيانات الذاكرة المعرفية (`memory_db.json`) ذرياً، والتحقق من سلامة البنية، وتدبير تدوير النسخ القديمة بشكل تلقائي.
- **التصميم**:
  - تم بناء وتطوير فئة إدارة النسخ الاحتياطي `PhoenixBackupManager` في الملف [backup.py](file:///c:/Users/1/Desktop/7070/ai_project/utils/backup.py) لإنشاء نسخ زمنية مخصصة داخل مجلد `ai_project/memory/backups/`.
  - تتم عملية النسخ بشكل ذري وآمن عبر النسخ لملف مؤقت بصيغة `.tmp` أولاً، ثم إجراء استبدال ذري مع الاسم الفعلي لضمان عدم حدوث عطب أثناء كتابة البيانات.
  - يتم فحص سلامة وتماسك بنية الJSON للنسخة المؤقتة (عن طريق تحميلها والتحقق من احتوائها على مفاتيح memories و kg_graph) قبل إتمام الاستبدال.
  - يقوم النظام تلقائياً بتدوير النسخ وحذف القديم منها والاحتفاظ بآخر 5 نسخ فقط.
  - تم ربط وتوفير واجهة سطر أوامر أمنية تدعم استدعاء العملية عبر `/api/admin/backup`.
